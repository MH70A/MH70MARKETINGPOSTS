- **Frontend:** HTML5, Tailwind CSS, FontAwesome 6.4.0, Inter Google Fonts.
- **SEO & GEO:** Embedded Schema Markup (JSON-LD) for entity resolution and AI search engine optimization.
- **Deployment & Hosting:** Continuous Deployment via Netlify & Git Gateway.
- **CMS:** Decap CMS (Netlify CMS) for automated article and blog publishing.
